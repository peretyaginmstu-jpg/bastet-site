# Бастет — сайт санитарной службы

Одностраничный сайт санитарной службы «Бастет» (ИП Азиев Р. Р., Москва): дезинсекция, дератизация,
акарицидная обработка и дезинфекция.

**Сайт:** https://peretyaginmstu-jpg.github.io/bastet-site/
**Будущий домен:** `bastet-dez.ru` (уже указан в canonical, OG-разметке, `sitemap.xml` и `robots.txt`)

## Коротко о проекте

- Статический сайт: семантический HTML, CSS и vanilla JS. Без сборщика, фреймворков и зависимостей.
- Нет бэкенда: сайт не отправляет и не хранит заявки. Форма собирает текст заявки и открывает
  почтовое приложение посетителя (`mailto:`) или копирует текст в буфер обмена.
- Контакты: телефон и электронная почта.
- Шрифты подключены локально: Prata 400 для заголовков (OFL) и Inter variable 400–700.
- Изображения в трёх форматах (AVIF, WebP, JPEG) и нескольких размерах для `srcset`.

### Разделы главной страницы

| Якорь | Раздел |
|---|---|

Отдельная страница — `privacy.html` (политика обработки персональных данных).

## Локальный запуск

Нужен только Python 3:

```sh
git clone https://github.com/peretyaginmstu-jpg/bastet-site.git
cd bastet-site
python3 devserver.py 8747
```

Сайт откроется по адресу http://127.0.0.1:8747/. Сервер слушает только localhost и отдаёт файлы
с отключённым кешированием, поэтому правки видны сразу после обновления страницы.

Полезные параметры адреса:

- `?qa=1` — отключает анимации появления блоков (для скриншотов);
- `privacy.html?review=1` — показывает служебные пометки `[ПРОВЕРИТЬ]` в тексте политики.

## Проверки

Офлайн-проверки, нужен только Node.js:

```sh
node tools/verify-static.mjs   # ссылки, srcset, семантика, alt, контрасты, обязательный контент
node tools/verify-picker.mjs   # все комбинации «объект × проблема» в логике подбора
```

Браузерные проверки и скриншоты (нужен запущенный `devserver.py`):

```sh
node tools/verify.mjs http://127.0.0.1:8747            # геометрия, работа без JS, сценарий подбора
node tools/verify-editorial.mjs http://127.0.0.1:8747  # вёрстка на разных ширинах, контраст
node tools/render.mjs http://127.0.0.1:8747/ out.png 1440 900 1 1
```

> Браузерные скрипты сейчас настроены на машину автора: используют установленный Google Chrome
> (путь macOS) и `playwright-core` из соседнего проекта. Для запуска в другом окружении поправьте
> `executablePath` и путь в `createRequire` в начале скрипта. Результаты пишутся в `_dev/qa-v5/`.

## Публикация

Каждый push в `main` запускает [`.github/workflows/pages.yml`](.github/workflows/pages.yml), который
публикует на GitHub Pages только файлы сайта:

- `index.html`, `privacy.html`
- `css/`, `js/`, `assets/`
- `robots.txt`, `sitemap.xml`

`brand/`, `tools/`, `devserver.py` и `README.md` остаются в репозитории, но на сайт не попадают.
Папка `_dev/` (рабочие материалы, QA-снимки, исходники изображений) хранится только локально и
исключена через `.gitignore`.

При переносе на другой хостинг выкладывайте тот же набор файлов.

**Подключение домена.** После регистрации `bastet-dez.ru` укажите его в настройках репозитория:
*Settings → Pages → Custom domain*. Адреса в разметке менять не нужно.

## Логотип

Логотип — монограмма «Б» из тонких линий над надписью «БАСТЕТ», цвет `#556B57`
(CSS-переменная `--sage-deep`). Он перерисован в вектор, единственный источник — генератор:

```sh
python3 brand/build-logo.py
```

Скрипт создаёт:

- `brand/bastet-logo.svg`, `bastet-logo-white.svg`, `bastet-monogram.svg`, `bastet-app-icon.svg`;
- `brand/sprite-symbols.txt` — символ `#logo-bastet` для SVG-спрайта;
- `assets/icons/favicon.svg`.

После изменения генератора замените символ `#logo-bastet` в спрайтах `index.html` и `privacy.html`
содержимым `brand/sprite-symbols.txt`. PNG-файлы (иконки приложения, OG-обложка, логотипы без фона)
рендерятся из HTML-страниц в `brand/`; команды указаны в комментариях этих страниц.
Прежний знак с кошкой сохранён в `brand/archive-cat/`.

Если заказчик пришлёт официальный SVG логотипа (после покупки в Turbologo), замените им перерисовку.

## Изображения

`tools/build-images.sh` пересобирает AVIF/WebP/JPEG всех размеров из исходных PNG в
`_dev/image-sources/`. Нужен ImageMagick (`magick`).

## Перед запуском на боевом домене

- [ ] Зарегистрировать домен `bastet-dez.ru` и подключить его в GitHub Pages.
- [ ] Утвердить у заказчика текст политики ПДн (сейчас он типовой). После утверждения удалить пометку
      `[ПРОВЕРИТЬ]` из `privacy.html` и проверки этого маркера в `tools/verify-static.mjs` и `tools/verify.mjs`.
- [ ] Добавить скан лицензии, когда он будет (заглушки на сайте нет намеренно).
